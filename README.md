  layout.css, komponen.css, tema.css

### Token yang saya tetapkan

| Token             |                            Nilai | Untuk apa                                                    |
| ----------------- | -------------------------------: | ------------------------------------------------------------ |
| `--color-primary` |                        `#14213d` | warna utama untuk tombol, header, navbar, dan elemen penting |
| `--color-fg`      |                        `#d4af37` | warna aksen untuk judul, highlight, hover, dan garis fokus   |
| `--color-bg`      |                        `#f5f1e8` | warna latar belakang halaman                                 |
| `--color-card`    |                        `#ffffff` | warna latar kartu, section, dan form                         |
| `--color-text`    |                        `#1f2933` | warna teks utama                                             |
| `--color-muted`   |                        `#666666` | warna teks sekunder seperti caption                          |
| `--color-border`  |                        `#dddddd` | warna border tabel dan input                                 |
| `--space-1`       |                            `4px` | jarak sangat kecil antar elemen                              |
| `--space-2`       |                            `8px` | jarak kecil untuk padding atau gap                           |
| `--space-3`       |                           `12px` | jarak sedang pada input dan elemen form                      |
| `--space-4`       |                           `16px` | jarak standar antar elemen                                   |
| `--space-6`       |                           `24px` | jarak besar untuk section, header, dan layout                |
| `--radius-md`     |                            `8px` | sudut membulat untuk tombol, input, kartu, dan gambar        |
| `--radius-full`   |                          `999px` | membuat elemen berbentuk bulat atau pill                     |
| `--shadow-1`      | `0 8px 24px rgba(0, 0, 0, 0.08)` | bayangan lembut pada kartu atau section                      |
| `--text-sm`       |                           `14px` | ukuran teks kecil seperti caption dan footer                 |
| `--text-md`       |                           `16px` | ukuran teks normal                                           |
| `--text-xl`       |                           `20px` | ukuran teks untuk subjudul                                   |
| `--text-3xl`      |                           `32px` | ukuran teks besar untuk judul utama                          |

Kriteria selesai saya: mengubah --color-primary di satu baris
harus mengubah warna tombol, --color-fg untuk judul utama dan garis fokus
